block float 8 — throughput across parts

Vector and matrix-engine throughput for this operand, on the parts whose vendors publish a rate for it.

Block float, abbreviated BFP. A block of values shares one exponent, and Tenstorrent prints the 8-bit form as BLOCKFP8. It is a different format from FP8, which has its own page. It is also the only format on this site where the empty cells mean something stronger than “unpublished”. Of the five architectures that own a matrix engine, only Tensix takes it, so this page compares three Tenstorrent cards against the rest of the parts' genuine absences rather than three unknowns.
