Bandwidth, and what each figure is a figure of

The one rate every part on this site publishes — and the one most easily compared wrongly, because three of these ten figures are not measuring the same thing as the other seven. Two are quoted per ASIC on a card that carries two, and one is not a frame buffer at all but system memory the CPU is reading from at the same time. Each bar says which it is.

Every figure is a published peak — a ceiling, not a measurement. No performance measurement of ours appears here.
